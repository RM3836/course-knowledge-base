# 02 - 防火墙配置

## 一、知识点总结

### 1. 华为防火墙安全区域与策略

- **安全区域**（Security Zone）：`Trust`、`Untrust`、`DMZ`、`Local`
- **安全策略优先级**：安全策略（`security-policy`）优先于 NAT 策略，未放行的流量即使配置 NAT 也会被丢弃
- **策略匹配顺序**：规则按配置顺序匹配，命中即停止

### 2. NAT 技术分类

| NAT 类型 | 用途 | 关键命令 |
|----------|------|----------|
| **源 NAT**（Source NAT） | 内网访问外网时转换源地址 | `nat address-group` + `nat-policy` |
| **NAT Server** | 公网用户访问内网服务器 | `nat server protocol tcp global ... inside ...` |
| **PAT / NAPT** | 多对一端口复用，节约公网 IP | `mode pat` 在地址池中配置 |

### 3. ASPF 与 ALG

- **ASPF**（Application Specific Packet Filter）：应用层包过滤，自动维护多通道协议的会话
- **ALG**（Application Layer Gateway）：应用层网关，解析 FTP/SIP 等协议的控制通道动态创建数据通道
- FTP 协议必须同时开启 ASPF 和 ALG，否则被动模式传输失败

### 4. 双机热备（VRRP + HRP）

- **VRRP**（虚拟路由冗余协议）：提供虚拟网关 IP，主设备故障时备设备自动接管
- **HRP**（Huawei Redundancy Protocol）：华为私有协议，同步安全策略和会话表
- **VGMP**：统一管理 VRRP 备份组，保证主备一致性
- 心跳线：独立网段，加入 `DMZ` 区域，配置 HRP 对端 IP

### 5. 虚拟化防火墙（vsys）

- **resource-class**：资源分配模板，限制会话数、策略数、带宽
- **vsys enable**：开启虚拟系统功能
- **vsys name**：创建虚拟系统并绑定接口和资源模板
- 虚拟-根路由：`ip route-static 0.0.0.0 0 public`
- 虚拟-虚拟路由：`ip route-static vpn-instance vsys2 x.x.x.x mask vpn-instance vsys1`

## 二、实操步骤

### 实验一：安全策略 + 源 NAT（内网访问外网）

**步骤 1** — 配置接口 IP
```bash
[FW] interface GigabitEthernet 0/0/0
[FW-GigabitEthernet0/0/0] ip address 10.1.1.254 255.255.255.0
[FW-GigabitEthernet0/0/0] quit
[FW] interface GigabitEthernet 1/0/0
[FW-GigabitEthernet1/0/0] ip address 1.1.1.1 255.255.255.0
[FW-GigabitEthernet1/0/0] quit
```

**步骤 2** — 划分安全区域
```bash
[FW] firewall zone trust
[FW-zone-trust] add interface GigabitEthernet 0/0/0
[FW-zone-trust] quit
[FW] firewall zone untrust
[FW-zone-untrust] add interface GigabitEthernet 1/0/0
[FW-zone-untrust] quit
```

**步骤 3** — 配置安全策略（阻止特定 IP，放行子网）
```bash
[FW] security-policy
[FW-policy-security] rule name block_ips
[FW-policy-security-rule-block_ips] source-zone trust
[FW-policy-security-rule-block_ips] destination-zone untrust
[FW-policy-security-rule-block_ips] source-address 172.16.1.1 32
[FW-policy-security-rule-block_ips] source-address 172.16.1.2 32
[FW-policy-security-rule-block_ips] source-address 172.16.1.3 32
[FW-policy-security-rule-block_ips] action deny
[FW-policy-security-rule-block_ips] quit
[FW-policy-security] rule name allow_subnet
[FW-policy-security-rule-allow_subnet] source-zone trust
[FW-policy-security-rule-allow_subnet] destination-zone untrust
[FW-policy-security-rule-allow_subnet] source-address 172.16.1.0 24
[FW-policy-security-rule-allow_subnet] action permit
```

**步骤 4** — 配置源 NAT 地址池
```bash
[FW] nat address-group group1
[FW-address-group-group1] mode pat
[FW-address-group-group1] section 0 1.1.1.10 1.1.1.15
[FW-address-group-group1] route enable
[FW-address-group-group1] quit
```

**步骤 5** — 配置 NAT 策略
```bash
[FW] nat-policy
[FW-policy-nat] rule name nat_internet
[FW-policy-nat-rule-nat_internet] source-zone trust
[FW-policy-nat-rule-nat_internet] destination-zone untrust
[FW-policy-nat-rule-nat_internet] source-address 172.16.1.0 24
[FW-policy-nat-rule-nat_internet] action source-nat address-group group1
```

**步骤 6** — 验证
```bash
display security-policy hit
display firewall session table
display nat address-group all
```

### 实验二：NAT Server + ALG（公网访问内网 FTP）

**步骤 1** — 配置安全策略
```bash
[FW] security-policy
[FW-policy-security] rule name ftp_access
[FW-policy-security-rule-ftp_access] source-zone untrust
[FW-policy-security-rule-ftp_access] destination-zone dmz
[FW-policy-security-rule-ftp_access] destination-address 10.2.0.8 32
[FW-policy-security-rule-ftp_access] action permit
```

**步骤 2** — 配置 NAT Server 映射
```bash
[FW] nat server policy_ftp protocol tcp global 1.1.1.10 ftp inside 10.2.0.8 ftp
```

**步骤 3** — 开启 FTP ASPF + ALG
```bash
[FW] firewall interzone dmz untrust
[FW-interzone-dmz-untrust] detect ftp
```

**步骤 4** — 验证
```bash
display nat server
display firewall server-map
telnet 1.1.1.10 21
```

### 实验三：双机热备（VRRP + HRP）

**步骤 1** — 配置接口 IP（FW1 为例）
```bash
[FW1] interface GigabitEthernet 0/0/0
[FW1-GigabitEthernet0/0/0] undo shutdown
[FW1-GigabitEthernet0/0/0] ip address 202.100.1.2 255.255.255.0
[FW1-GigabitEthernet0/0/0] quit
[FW1] interface GigabitEthernet 1/0/0
[FW1-GigabitEthernet1/0/0] undo shutdown
[FW1-GigabitEthernet1/0/0] ip address 10.1.10.2 255.255.255.0
[FW1-GigabitEthernet1/0/0] quit
```

**步骤 2** — 配置 VGMP（FW1 为主设备）
```bash
[FW1] interface GigabitEthernet 0/0/0
[FW1-GigabitEthernet0/0/0] vrrp vrid 1 virtual-ip 202.100.1.254 active
[FW1-GigabitEthernet0/0/0] vrrp vrid 1 priority 150
[FW1-GigabitEthernet0/0/0] quit
[FW1] interface GigabitEthernet 1/0/0
[FW1-GigabitEthernet1/0/0] vrrp vrid 2 virtual-ip 10.1.10.254 active
[FW1-GigabitEthernet1/0/0] vrrp vrid 2 priority 150
[FW1-GigabitEthernet1/0/0] quit
```

**步骤 3** — 配置心跳线（独立网段 10.10.0.0/24）
```bash
[FW1] interface GigabitEthernet 1/0/1
[FW1-GigabitEthernet1/0/1] ip address 10.10.0.1 255.255.255.0
[FW1-GigabitEthernet1/0/1] quit
[FW1] firewall zone dmz
[FW1-zone-dmz] add interface GigabitEthernet 1/0/1
[FW1-zone-dmz] quit
```

**步骤 4** — 配置 HRP
```bash
[FW1] hrp interface GigabitEthernet 1/0/1 remote 10.10.0.2
[FW1] hrp enable
[FW1] vgmp priority 150
```

**步骤 5** — 配置静态路由
```bash
[FW1] ip route-static 0.0.0.0 0.0.0.0 202.100.1.1
```

**步骤 6** — 验证
```bash
display vrrp
display hrp state
```
> 在 FW1 上 shutdown 接口模拟故障，观察 FW2 是否接管（PC1 ping PC3 不中断）

### 实验四：虚拟化防火墙

**步骤 1** — 创建资源分配模板
```bash
[FW] resource-class r1
[FW-resource-class-r1] resource-item-limit session reserved-number 500 maximum 1000
[FW-resource-class-r1] resource-item-limit policy reserved-number 200
[FW-resource-class-r1] resource-item-limit bandwidth 5 entire
```

**步骤 2** — 创建虚拟系统并绑定资源
```bash
[FW] vsys enable
[FW] vsys name vsys1
[FW-vsys-vsys1] assign resource-class r1
[FW-vsys-vsys1] assign interface g1/0/0
```

**步骤 3** — 虚拟-根路由
```bash
ip route-static 0.0.0.0 0 public
```

**步骤 4** — 虚拟-虚拟路由（vsys1 访问 vsys2）
```bash
ip route-static vpn-instance vsys2 10.3.1.0 255.255.255.0 vpn-instance vsys1
```

## 三、常见问题与排错

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `The interface has been added to xxx zone` | 接口已绑定到其他区域 | 先 `undo` 解绑再重新绑定 |
| `Ambiguous command found` | 命令缩写不唯一，有多个匹配 | 输入更完整的命令前缀 |
| `Unrecognized command` | 拼写错误（如 `estination` 少了 `d`） | 检查命令拼写，用 `?` 查看可用命令 |
| `Wrong parameter found` | 接口号写错（如心跳线用错接口） | `display interface brief` 确认接口编号 |
| NAT 配置后仍无法上网 | 安全策略未放行 | 先配 `security-policy` permit，再配 NAT |
| FTP 被动模式传输失败 | 未开启 ASPF + ALG | `firewall interzone` 下执行 `detect ftp` |
| HRP 状态始终为 standby | 心跳线不通或对端 IP 配错 | 检查心跳接口 IP 和 `hrp interface` 命令 |
| 双机热备不切换 | VRRP 优先级相同或抢占关闭 | 调整优先级，确认 `vgmp preempt-mode` |

## 四、速记口诀

```
防火墙配置四字诀：区 → 策 → NAT → 路
安全区域先划分，策略放行再做 NAT，静态路由最后查

源 NAT 记忆法：
地址池建(PAT) → 策略写(source-nat) → 策略放行(permit)

NAT Server 记忆法：
global 是外，inside 是内，端口要对映

双机热备三步走：
VRRP 建虚 IP，HRP 连心跳，VGMP 统一管
主备优先级不同记：主 150，备 100

ASPF + ALG 口诀：
FTP 多通道，ASPF 查动态，ALG 解应用

虚拟化防火墙：
资源模板限上限，vsys 绑定接口和模板
路由三式：根 → 公共，虚拟 → 根 → public，跨虚拟 → vpn-instance
```
