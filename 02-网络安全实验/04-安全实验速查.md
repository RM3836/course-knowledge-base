# 04 - 安全实验命令速查表

## 一、Nmap 扫描命令

| 用途 | 命令 |
|------|------|
| 存活主机发现 | `nmap -sn 192.168.1.0/24` |
| 全端口服务扫描 | `nmap -T4 -A -p- -Pn -sV <target>` |
| 操作系统识别 | `nmap -O <target>` |
| 快速 SYN 扫描 | `nmap -sS -sV -T4 -v -n --open --reason <target>` |
| 指定端口扫描 | `nmap -p 135,445,3389 <target>` |
| ICMP 主机发现 | `nmap -sP 192.168.159.0/24` |

## 七、华为防火墙 CLI 命令

### 基础配置

| 用途 | 命令 |
|------|------|
| 进入接口 | `interface GigabitEthernet x/x/x` |
| 配置 IP | `ip address <ip> <mask>` |
| 启用接口 | `undo shutdown` |
| 添加到安全区域 | `firewall zone <trust/untrust/dmz/local>` → `add interface gX/X/X` |

### 安全策略

| 用途 | 命令 |
|------|------|
| 进入策略视图 | `security-policy` |
| 创建规则 | `rule name <名称>` |
| 设置源区域 | `source-zone <zone>` |
| 设置目的区域 | `destination-zone <zone>` |
| 设置源地址 | `source-address <ip> <mask>` |
| 设置目的地址 | `destination-address <ip> <mask>` |
| 设置服务 | `service <icmp/ssh/tcp/udp>` |
| 设置动作 | `action <permit/deny>` |

### NAT 配置

| 用途 | 命令 |
|------|------|
| 创建 NAT 地址池 | `nat address-group <name>` |
| 地址池模式 PAT | `mode pat` |
| 地址池范围 | `section 0 <start-ip> <end-ip>` |
| 路由发布地址池 | `route enable` |
| 进入 NAT 策略 | `nat-policy` |
| 源 NAT 动作 | `action source-nat address-group <name>` |
| NAT Server 映射 | `nat server <name> protocol tcp global <pub-ip> <port> inside <priv-ip> <port>` |

### ASPF 与 ALG

| 用途 | 命令 |
|------|------|
| 开启 FTP 检测 | `firewall interzone <z1> <z2>` → `detect ftp` |

### 双机热备

| 用途 | 命令 |
|------|------|
| 配置 VRRP 虚 IP | `vrrp vrid <id> virtual-ip <ip> active/standby` |
| VRRP 优先级 | `vrrp vrid <id> priority <value>` |
| 开启 HRP | `hrp enable` |
| HRP 心跳接口 | `hrp interface gX/X/X remote <peer-ip>` |
| VGMP 优先级 | `vgmp priority <value>` |
| 查看 VRRP 状态 | `display vrrp` |
| 查看 HRP 状态 | `display hrp state` |

### 虚拟化防火墙

| 用途 | 命令 |
|------|------|
| 开启虚拟系统 | `vsys enable` |
| 创建虚拟系统 | `vsys name <name>` |
| 绑定资源模板 | `assign resource-class <name>` |
| 绑定接口 | `assign interface gX/X/X` |
| 资源模板限制会话 | `resource-item-limit session reserved-number <n> maximum <n>` |
| 虚拟-根路由 | `ip route-static 0.0.0.0 0 public` |
| 跨虚拟路由 | `ip route-static vpn-instance <dst> <ip> <mask> vpn-instance <src>` |

### 验证与诊断

| 用途 | 命令 |
|------|------|
| 查看策略命中 | `display security-policy hit` |
| 查看会话表 | `display firewall session table` |
| 查看会话详情 | `display firewall session table verbose` |
| 查看 NAT 地址池 | `display nat address-group all` |
| 查看 NAT Server | `display nat server` |
| 查看 Server-Map | `display firewall server-map` |
| 查看接口状态 | `display interface brief` |
| 静态路由 | `ip route-static 0.0.0.0 0.0.0.0 <next-hop>` |

## 八、速记口诀总汇

```
Nmap 六字诀：-sn 找人，-sS 敲门，-A 摸底

MSF 四步走：搜(search) → 选(use) → 设(set) → 跑(run)

渗透五步法：收集 → 扫描 → 漏洞 → 利用 → 提权

防火墙配置四字诀：区 → 策 → NAT → 路
区域划分排第一，策略放行第二步，NAT 转换第三步，静态路由最后补

双机热备三件套：VRRP 建虚 IP，HRP 连心跳，VGMP 统一管

NAT 三种记法：
源 NAT → 内转外（私网出去）
NAT Server → 外转内（公网进来）
PAT → 端口复用省 IP

关键验证四要素：
安全策略命中 → NAT 转换 → 会话表 → Server-map 表
```
