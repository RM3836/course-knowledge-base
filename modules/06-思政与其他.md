### Java 面向对象程序设计

**考核要求（A卷）**：
- 第1题（10分）：数据类型、运算符、表达式、分支循环综合应用
- 第2题（30分）：类对象、继承、接口、多态、AWT/Swing、数据库综合应用
- 第3题（10分）：项目报告（格式规范、内容完整）

**核心知识点**：

| 概念 | 要点 | 记忆 |
|------|------|------|
| 封装 | `private` 属性 + `public` getter/setter | 数据隐藏 |
| 继承 | `extends`，单继承，`super` 访问父类 | 代码复用 |
| 多态 | 方法重写 + 向上转型 + 动态绑定 | 父类引用指向子类对象 |
| 接口 | `interface`，全抽象，`implements` 实现 | 多继承替代方案 |
| 抽象类 | `abstract`，不能实例化，可有实现方法 | 半成品类 |

**常用设计模式**：
```java
// 单例模式
public class Singleton {
    private static Singleton instance;
    private Singleton() {}
    public static Singleton getInstance() {
        if (instance == null) instance = new Singleton();
        return instance;
    }
}

// MVC 模式：Model-View-Controller 分离
// Model: 数据逻辑  View: 界面显示  Controller: 事件处理
```

**AWT/Swing 常用组件**：
```java
JFrame frame = new JFrame("标题");      // 窗口
JPanel panel = new JPanel();              // 面板
JButton btn = new JButton("点击");       // 按钮
JTextField tf = new JTextField(20);       // 文本框
JLabel label = new JLabel("标签");        // 标签

// 布局管理器
frame.setLayout(new FlowLayout());    // 流式布局
frame.setLayout(new BorderLayout());  // 边界布局
frame.setLayout(new GridLayout(3,2)); // 网格布局
```

**常用命令**：

## ❓ 常见问题与排错

| 问题 | 原因 | 解决 |
|------|------|------|
| ENSP 设备启动失败 | VirtualBox 版本不兼容 | 用 ENSP 推荐的 VirtualBox 版本 |
| Java 编译报编码错误 | 源文件含中文但未指定编码 | `javac -encoding UTF-8` |
| ENSP 路由器一直 `####` | CPU 虚拟化未开启 | BIOS 开启 VT-x/AMD-V |
| Swing 界面不显示 | 未调用 `setVisible(true)` | 在组件添加完成后调用 |
