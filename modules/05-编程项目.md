## 一、知识点总结

### 1. WEB服务器项目（C语言实现）

#### 核心技术栈
- **语言**：C语言（后端）+ HTML/CSS（前端）
- **协议**：HTTP协议（请求报文 + 响应报文）
- **通信**：Socket套接字编程
- **架构**：守护进程 + 多线程处理请求

#### HTTP协议要点
- **请求报文**：请求行 + 请求头部 + 空行 + 请求数据
- **响应报文**：状态行 + 消息报头 + 空行 + 响应正文
- **状态码**：200 OK、404 Not Found、501 Method Not Implemented

#### GET vs POST 区别
| 特性 | GET | POST |
|------|-----|------|
| 回退行为 | 无害，不重新提交 | 会重新提交请求 |
| URL收藏 | 可以 | 不可以 |
| 浏览器缓存 | 自动缓存 | 默认不缓存 |
| 参数位置 | URL中 | 请求体中 |
| 参数长度 | 有限制 | 无限制 |
| 数据类型 | 仅ASCII | 无限制 |
| 安全性 | 较低（参数暴露） | 较高 |

#### 套接字通信流程
```
服务器端：socket() → bind() → listen() → accept() → read/write → close()
客户端：  socket() → connect() → read/write → close()
```

## 三、关键代码片段

### 1. 守护进程创建（C语言）
```c
void init_daemon() {
    pid_t pid;
    pid = fork();          // 第一次fork
    if (pid > 0) exit(0);  // 父进程退出
    if (pid < 0) exit(1);  // fork失败
    
    setsid();              // 创建新会话，脱离控制终端
    
    pid = fork();          // 第二次fork
    if (pid > 0) exit(0);  // 第一子进程退出
    if (pid < 0) exit(1);
    
    // 第二子进程继续运行
    for (int i = 0; i < 64; i++) close(i);  // 关闭文件描述符
    umask(0);              // 重置文件创建掩码
}
```

### 2. 套接字创建与监听（C语言）
```c
int start(int *port) {
    int server_sock = socket(AF_INET, SOCK_STREAM, 0);
    
    struct sockaddr_in server_addr;
    server_addr.sin_family = AF_INET;
    server_addr.sin_port = htons(*port);
    server_addr.sin_addr.s_addr = INADDR_ANY;
    
    bind(server_sock, (struct sockaddr*)&server_addr, sizeof(server_addr));
    listen(server_sock, 5);
    
    return server_sock;
}
```

## 四、常见问题

### WEB服务器相关

**Q1：服务器启动后浏览器访问显示空白？**
A：检查HTML文件路径是否正确，确认web服务器的工作目录包含Index.html。

**Q2：GET请求参数解析不正确？**
A：检查URL编码，特殊字符（中文、空格）需要URL编码处理。GET参数在`?`后面，以`&`分隔。

**Q3：POST请求读取不到数据？**
A：POST数据在请求体中，需要先从Header中获取`Content-Length`，然后读取对应长度的数据。

**Q4：守护进程创建后无法调试？**
A：守护进程脱离了控制终端，调试时可以注释掉`init_daemon()`调用，改为前台运行。

### Python爬虫相关

**Q5：Selenium启动Chrome报错"chromedriver版本不匹配"？**
A：下载与Chrome浏览器版本匹配的ChromeDriver。检查Chrome版本：`chrome://version/`。

**Q6：12306登录等待超时？**
A：`WebDriverWait`的timeout设置太短，或页面加载慢。可增大超时时间或检查网络。

**Q7：Bilibili API返回空数据？**
A：检查User-Agent是否设置，API可能需要登录Cookie。部分API有反爬限制。

**Q8：正则匹配不到车站代码？**
A：检查网页编码是否为UTF-8，正则表达式是否匹配中文Unicode范围`[\u4e00-\u9fa5]`。

**Q9：Selenium中`send_keys()`输入无效？**
A：对于12306等网站，输入框可能是只读的。需要使用`execute_script()`直接设置value属性：
```python
driver.execute_script("arguments[0].value=arguments[1];", element, value)
```
