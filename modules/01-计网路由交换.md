# 01 - 计算机网络与路由交换

## 📖 知识点总结

### 核心概念

- **计算机网络基本功能**：数据通信（最基本）、资源共享、分布式处理
- **网络分类依据**：拓扑结构（星形/总线型/环形/网状）、覆盖范围（LAN/WAN）、通信方式
- **OSI 七层模型**：物理→数据链路→网络→传输→会话→表示→应用
- **TCP/IP 四层模型**：网络接口→网际层→传输层→应用层

### OSI 各层核心功能

| 层次 | 功能 | 数据单元 | 关键协议 |
|------|------|----------|----------|
| 物理层 | 比特流传输 | Bit | — |
| 数据链路层 | 物理寻址、流量控制、差错控制 | Frame | Ethernet, PPP |
| 网络层 | 路由选择、拥塞控制 | Packet | IP, OSPF, RIP |
| 传输层 | 端到端应答、分组排序、流量控制 | Segment | TCP, UDP |
| 会话层 | 建立/管理/终止会话 | — | — |
| 表示层 | 数据加密、压缩、格式转换 | — | — |
| 应用层 | 用户接口 | — | HTTP, DNS, FTP |

### 关键协议速查

| 协议 | 功能 | 记忆要点 |
|------|------|----------|
| `ARP` | IP → MAC 地址解析 | 网络层协议 |
| `DNS` | 域名 → IP 解析 | 应用层协议 |
| `DHCP` | 动态分配 IP/子网掩码/网关 | 自动配置 |
| `NAT` | 私有地址 ↔ 公有地址转换 | 节省公网IP |
| `OSPF` | 链路状态路由协议 | 开放最短路径优先 |
| `RIP` | 距离矢量路由协议 | 最大15跳 |

### 私有地址范围（RFC 1918）

| 类别 | 范围 | 子网掩码 |
|------|------|----------|
| A 类 | `10.0.0.0 ~ 10.255.255.255` | `/8` |
| B 类 | `172.16.0.0 ~ 172.31.255.255` | `/12` |
| C 类 | `192.168.0.0 ~ 192.168.255.255` | `/16` |

### 传输方式

- **串行传输**：数据位按顺序逐位传输（单条信道）
- **并行传输**：数据以成组方式在多条信道上同时传输
- **单工**：只能单向传输（广播）
- **半双工**：可双向但交替进行（对讲机）
- **全双工**：可同时收发（电话）

### 线缆标准

| 标准 | 线序 |
|------|------|
| T568B | 橙白、橙、绿白、蓝、蓝白、绿、棕白、棕 |
| T568A | 绿白、绿、橙白、蓝、蓝白、橙、棕白、棕 |
| 直通线 | 两端相同线序（不同设备：PC↔交换机） |
| 交叉线 | 一端A一端B（相同设备：PC↔PC） |

### DNS 域名解析过程

```
用户输入 www.baidu.com
  ↓
1. 检查本地缓存（浏览器→操作系统）
  ↓ 未命中
2. 查询本地 DNS 服务器
  ↓ 未命中
3. 查询根域名服务器 → 返回 .com 顶级域地址
  ↓
4. 查询 .com 顶级域 → 返回 baidu.com 权威域地址
  ↓
5. 查询权威域名服务器 → 返回 www.baidu.com 的 IP
  ↓
6. 缓存结果，返回给主机
```

## 📝 选择题精选

### 计算机网络基础

> **1. 计算机网络最基本的功能是？**
> A. 数据通信　B. 资源共享　C. 分布式处理　D. 信息综合处理
>
> **答案：A** — 数据通信是最基本功能，其他都是在此基础上的扩展

> **2. 协议是指在（）之间进行通信的规则或约定？**
> A. 同一节点的上下层　B. 不同节点　C. 相邻实体　D. 不同节点对等实体
>
> **答案：D** — 协议是**对等实体**之间的规则，不是上下层关系

> **3. OSI 参考模型中数据链路层不具有（）功能？**
> A. 物理寻址　B. 流量控制　C. 差错控制　D. 拥塞控制
>
> **答案：D** — 拥塞控制是**网络层**的功能

> **4. 实现端到端应答、分组排序和流量控制的层次是？**
> A. 会话层　B. 网络层　C. 传输层　D. 数据链路层
>
> **答案：C** — 传输层负责端到端（End-to-End）的可靠传输

### 路由交换

> **5. 华为路由器从用户视图进入系统视图的命令是？**
> A. system-view　B. enable　C. configure terminal　D. interface system
>
> **答案：A** — `system-view` 是华为命令，`configure terminal` 是思科命令

> **6. 查看 IP 路由表的命令是？**
> A. display routingtable　B. display ip route-table　C. display route-table　D. display ip routing-table
>
> **答案：D** — 完整命令是 `display ip routing-table`

> **7. 路由信息的来源不包括？**
> A. 默认路由　B. 直连路由　C. 静态路由　D. 动态路由
>
> **答案：A** — 路由来源只有三种：直连、静态、动态

> **8. 路由优先级的比较规则是？**
> A. 数值最小的放入路由表　B. 数值最大的放入路由表
> C. 代价最小的放入路由表　D. 代价最大的放入路由表
>
> **答案：A** — 路由优先级数值越小越优先（直连=0，静态=60，RIP=100，OSPF=10）

## 🔧 综合应用题答题模板

### 子网划分计算

**题目模板**：某公司有 N 个部门，每个部门 M 台电脑，使用 C 类网络 X.X.X.0/24 划分子网

**解题步骤**：
```
1. 确定需要的子网数（N个部门 → 需要N个子网）
2. 确定每个子网需要的主机数（M台 → 需要 M+2 个地址）
3. 从主机位借位：2^n >= N（子网数），2^m - 2 >= M（主机数）
4. 新子网掩码 = 原掩码 + 借位数
5. 每个子网大小 = 2^m
```

**示例**：3个部门各60台，212.16.56.0/24
```
需要3个子网，每子网≥60个IP
借2位：2²=4≥3，剩余6位：2⁶-2=62≥60 ✓
新子网掩码：255.255.255.192（/26）
子网1：212.16.56.0/26   → 可用 .1~.62，广播 .63
子网2：212.16.56.64/26  → 可用 .65~.126，广播 .127
子网3：212.16.56.128/26 → 可用 .129~.190，广播 .191
```

### CRC 校验码计算

**步骤**：
```
1. 写出生成多项式对应的二进制（如 X⁴+X³+1 → 11001）
2. 数据位后加 n 个0（n=最高阶数=4）
3. 做模2除法（异或运算）
4. 余数就是CRC校验码
5. 最终发送 = 原数据 + CRC校验码
```

### 华为路由器配置模板

```bash
# 接口IP配置
[R2]int s0/0/1
[R2-Serial0/0/1] ip address 172.16.12.2 255.255.255.252

# 静态路由
[R2]ip route-static 172.16.10.0 24 s0/0/1

# 默认路由
[R1]ip route-static 0.0.0.0 0.0.0.0 s0/0/1

# RIP动态路由
[R3]rip 1
[R3-rip-1]version 2
[R3-rip-1]network 172.16.0.0

# OSPF动态路由
[R3]ospf 1
[R3-ospf-1]area 0
[R3-ospf-1-area-0.0.0.0]network 172.16.11.0 0.0.0.255

# 查看命令
display ip interface brief   # 查看接口IP
display ip routing-table     # 查看路由表
display current-configuration # 查看当前配置
```

## ❓ 常见问题与排错

| 问题 | 原因 | 解决 |
|------|------|------|
| Telnet 无法配置命令 | 未设置 Telnet 用户级别 | 设置用户级别为 3（管理级） |
| 静态路由从路由表消失 | 出接口不可用 | 检查物理连接和接口状态 |
| RIP 不收敛 | 最大跳数15限制 | 改用 OSPF 或检查网络拓扑 |
| OSPF 邻居建不起来 | Area ID 不匹配 | 确保相邻路由器在同一 Area |
| 子网划分后部分主机不通 | 子网掩码配置错误 | 检查 `ipconfig` 确认掩码 |

## 🧠 速记口诀

> **OSI 七层**：物数网传会表应（物理、数据链路、网络、传输、会话、表示、应用）

> **路由优先级**：直连0 > 静态60 > OSPF100 > RIP150（数值小的优先）

> **线缆记忆**：直通不同设备，交叉同设备（同交直不同——同种设备交叉线，不同设备直通线）

> **私有地址**：A类10开头，B类172.16-31，C类192.168（10/172/192 三段私有）

> **DNS解析**：本地→根→顶级→权威（四步递归，缓存优先）

> **RIP vs OSPF**：RIP 数跳数（最大15），OSPF 算带宽（开销值）
