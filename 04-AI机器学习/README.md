# 04-AI机器学习

本模块包含人工智能与机器学习实验的完整知识体系，涵盖分类、回归、聚类三大任务类型。

## 目录

### [01-分类预测](01-分类预测.md)
- **算法**：KNN、决策树、SVM
- **数据集**：鸢尾花（Iris）数据集，150样本，4特征，3类别
- **内容**：算法原理、参数优化、模型对比、新样本预测
- **评估**：准确率、精确率、召回率、F1-Score
- **结论**：花瓣特征区分度最高，三种算法准确率0.93-1.0

### [02-回归分析](02-回归分析.md)
- **算法**：线性回归、Ridge回归
- **数据集**：波士顿房价数据集，506样本，12特征
- **内容**：EDA可视化、特征重要性、Ridge参数调优
- **评估**：MSE、RMSE、R²、MAE
- **结论**：RM（房间数）正相关最强（0.7），LSTAT负相关最强（-0.74）

### [03-聚类分析](03-聚类分析.md)
- **算法**：K-Means聚类
- **数据集**：商场客户数据集，200样本，5特征
- **内容**：肘部法则选K、标准化预处理、客户分群、业务解读
- **评估**：WCSS、轮廓系数
- **结论**：客户分为5群，高收入高消费和低收入高消费是重点运营对象

### [04-代码模板](04-代码模板.md)
- **环境设置**：库导入、中文显示、随机种子
- **数据加载**：sklearn数据集、CSV加载、数据探索
- **可视化模板**：直方图、散点图、箱线图、热力图、柱状图
- **预处理模板**：数据划分、标准化
- **模型模板**：KNN、决策树、SVM、线性回归、Ridge、K-Means
- **评估指标速查**：分类和回归的常用指标

## 核心知识图谱

```
机器学习
├── 监督学习
│   ├── 分类（离散标签）
│   │   ├── KNN：基于距离的投票
│   │   ├── 决策树：基于特征分裂
│   │   └── SVM：寻找最优超平面
│   └── 回归（连续值）
│       ├── 线性回归：y = kx + b
│       └── Ridge回归：加L2正则化
└── 无监督学习
    └── 聚类
        └── K-Means：质心迭代优化
```
