# 02-回归分析

## 一、算法原理

### 线性回归

线性回归用线性方程拟合特征与连续目标变量的关系：

**单特征**：y = kx + b
**多特征**：y = k₁x₁ + k₂x₂ + … + kₙxₙ + b

训练过程：找到最优系数和截距，使预测值与真实值的均方误差（MSE）最小。

### Ridge回归（岭回归）

在线性回归基础上加入L2正则化项，防止过拟合：
- 损失函数 = MSE + α × Σ(kᵢ²)
- α为正则化强度参数，α越大正则化越强

## 二、Python代码实现

### 数据加载与预处理

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')
import matplotlib.pyplot as plt
import seaborn as sns

# 设置中文显示
plt.rcParams["font.family"] = ["SimHei", "WenQuanYi Micro Hei", "Heiti TC"]
plt.rcParams['axes.unicode_minus'] = False

# 加载波士顿房价数据集
data_url = "http://lib.stat.cmu.edu/datasets/boston"
raw_df = pd.read_csv(data_url, sep="\s+", skiprows=22, header=None)
data = np.hstack([raw_df.values[::2, :], raw_df.values[1::2, :2]])
target = raw_df.values[1::2, 2]

feature_names = ['CRIM', 'ZN', 'INDUS', 'CHAS', 'NOX', 'RM', 'AGE',
                 'DIS', 'RAD', 'TAX', 'PTRATIO', 'B', 'LSTAT']
df = pd.DataFrame(data, columns=feature_names)
df['MEDV'] = target  # 目标变量：房价中位数（千美元）

# 删除有伦理争议的'B'特征
df = df.drop(columns=['B'])

print(f"数据集形状: {df.shape}")
print(f"特征: {', '.join(df.columns[:-1])}")
print(f"\n统计描述:\n{df.describe()}")
```

### 模型训练与评估

```python
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.model_selection import GridSearchCV
from sklearn.metrics import mean_squared_error, r2_score

# 划分特征与目标变量
X = df.drop(columns=['MEDV'])
y = df['MEDV']

# 划分训练集和测试集（8:2）
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=30
)

# 特征标准化
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)  # 仅用训练集拟合
X_test_scaled = scaler.transform(X_test)

# 训练线性回归模型
lr_model = LinearRegression()
lr_model.fit(X_train_scaled, y_train)
y_pred = lr_model.predict(X_test_scaled)

# 评估指标
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)
print(f"MSE(均方误差): {mse:.3f}")
print(f"RMSE(均方根误差): {rmse:.3f} (千美元)")
print(f"R²(决定系数): {r2:.3f}")
```

### Ridge回归优化

```python
# 网格搜索最佳alpha
alpha_candidates = [0.01, 0.1, 1, 10, 50, 100]
ridge = Ridge(random_state=30)
grid_search = GridSearchCV(
    estimator=ridge,
    param_grid={'alpha': alpha_candidates},
    cv=5,
    scoring='r2'
)
grid_search.fit(X_train_scaled, y_train)

# 最佳模型评估
best_ridge = grid_search.best_estimator_
y_pred_ridge = best_ridge.predict(X_test_scaled)
r2_ridge = r2_score(y_test, y_pred_ridge)

print(f"最佳alpha值: {grid_search.best_params_['alpha']}")
print(f"优化后R²分数: {r2_ridge:.3f}")
print(f"原始模型R²分数: {r2:.3f}")
print(f"提升幅度: {(r2_ridge - r2):.3f}")
```

## 三、评估指标

| 指标 | 公式 | 含义 | 取值范围 |
|------|------|------|----------|
| MSE | Σ(y-ŷ)²/n | 均方误差，值越小越好 | [0, +∞) |
| RMSE | √MSE | 均方根误差，单位与目标变量一致 | [0, +∞) |
| R² | 1-Σ(y-ŷ)²/Σ(y-ȳ)² | 决定系数，模型解释能力 | (-∞, 1] |
| MAE | Σ|y-ŷ|/n | 平均绝对误差 | [0, +∞) |

**R²解释**：R²=0.698表示模型能解释69.8%的房价变化，剩余30.2%由未捕捉因素解释。

## 四、实验结论

- **核心发现**：平均房间数（RM）与房价正相关最强（相关系数0.7），低收入人群比例（LSTAT）负相关最强（-0.74）
- **模型效果**：线性回归测试集R²=0.698，经Ridge调优（最佳alpha=10）后R²提升至0.712
- **模型局限**：线性回归无法捕捉非线性关系（高价房预测偏低），未考虑特征交互作用
- **改进方向**：尝试多项式回归/随机森林处理非线性；构建交互特征（如RM×LSTAT）
