# 03-聚类分析

## 一、算法原理

### K-Means算法

K-Means将数据分成K个互不重叠的簇，使簇内平方和（WCSS）最小，簇间差异最大。

**计算流程**：
1. 随机选择K个数据点作为初始质心
2. 计算每个数据点到所有质心的距离（欧氏距离），归到最近质心所在簇
3. 重新计算每个簇的质心（簇内所有点的均值）
4. 重复步骤2-3，直到质心位置不再变化或达到最大迭代次数

**优化**：使用`init='k-means++'`初始化，避免随机初始化导致的局部最优。

### 肘部法则（Elbow Method）

用于确定最佳聚类数量K：
- WCSS随K增加而减小（簇越多，簇内差异越小）
- 当K增大到某个值时，WCSS下降幅度明显变缓，该点即为"肘部"
- 肘部对应的K值即为最佳聚类数

### 轮廓系数（Silhouette Score）

衡量聚类效果的指标：
- 取值范围[-1, 1]
- 值越接近1，聚类效果越好
- 值接近0，表示样本在簇边界
- 值接近-1，表示样本可能被分到了错误的簇

### 数据预处理（标准化）

```python
# 选择聚类特征：年收入和消费分数
X = df[['Annual Income (k$)', 'Spending Score (1-100)']]

# 标准化（解决量纲影响）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

X_scaled_df = pd.DataFrame(X_scaled, columns=['标准化年收入', '标准化消费分数'])
print(f"标准化后的前5行数据:\n{X_scaled_df.head()}")
```

**为什么要标准化？**
- 年收入范围20-137千美元，消费分数范围1-100
- 若不标准化，K-Means会过度依赖年收入（数值大的特征权重更高）
- 标准化后均值接近0，标准差接近1

### 肘部法则确定K值

```python
wcss = []
for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, init='k-means++', random_state=42)
    kmeans.fit(X_scaled)
    wcss.append(kmeans.inertia_)

plt.figure(figsize=(10, 6))
plt.plot(range(1, 11), wcss, marker='o', linestyle='-', color='blue', markersize=8)
plt.scatter(5, wcss[4], color='red', s=200, zorder=5, label='肘部(K=5)')
plt.xlabel('聚类数量K')
plt.ylabel('簇内平方和（WCSS）')
plt.title('肘部法则：确定最佳K值')
plt.xticks(range(1, 11))
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

### K-Means聚类

```python
# 使用K=5训练模型
kmeans = KMeans(n_clusters=5, init='k-means++', random_state=42)
y_pred = kmeans.fit_predict(X_scaled)
df['Cluster'] = y_pred

# 查看各簇客户数量

# 查看各簇特征均值（原始数据，便于业务解读）

cluster_analysis = df.groupby('Cluster')[['Age', 'Annual Income (k$)', 'Spending Score (1-100)']].mean()
print(cluster_analysis)
```

## 三、评估指标

| 指标 | 公式 | 含义 |
|------|------|------|
| WCSS（簇内平方和） | ΣΣ(x-μ)² | 簇内样本到质心的距离之和，越小越好 |
| 轮廓系数 | (b-a)/max(a,b) | [-1,1]，越接近1越好 |
| 簇间距离 | 质心间距离 | 越大说明簇间差异越大 |
| 各簇数量 | value_counts() | 各簇数量分布是否均匀 |

## 四、业务解读

**5类客户群特征**：
| 簇 | 年收入 | 消费分数 | 类型 | 营销建议 |
|----|--------|----------|------|----------|
| 0 | 中等 | 中等 | 中产稳健型 | 标准化服务 |
| 1 | 低 | 高 | 低收入高消费型 | 分期付款、优惠券 |
| 2 | 中等 | 中等 | 中等消费型 | 促销活动引导 |
| 3 | 高 | 高 | 高收入高消费型 | VIP专属服务 |
| 4 | 高 | 低 | 高收入低消费型 | 精准营销、提升消费意愿 |

## 五、实验结论

- **核心发现**：商场客户可分为5类，"高收入高消费型"和"低收入高消费型"是重点运营对象；女性客户占比更高，中青年是核心客群
- **模型局限**：K-Means对初始质心敏感（需用k-means++优化）；无法处理非球形簇
- **改进方向**：加入年龄、性别特征增加维度；尝试DBSCAN处理非球形数据
