# 06-思政与其他

本模块包含思想政治课程和ENSP网络基础命令的知识整理。

## 目录

### [01-马原复习](01-马原复习.md)
马克思主义基本原理概论完整复习资料，涵盖：
- **马克思主义创立**：理论来源（德国古典哲学、英国古典政治经济学、英法空想社会主义）和自然科学前提（三大发现）
- **基本特征**：科学性、人民性、实践性、发展开放性
- **唯物辩证法**：联系、矛盾、量变质变、辩证否定
- **认识论**：实践、认识过程、真理的绝对性与相对性
- **历史唯物主义**：生产方式、社会意识、生产力与生产关系、人民群众
- **政治经济学**：商品二因素、劳动二重性、价值规律、剩余价值、垄断与帝国主义
- **科学社会主义**：社会主义建设长期性、共产主义社会特征

### [02-Java面向对象](02-Java面向对象.md)
Java面向对象程序设计期末项目参考，涵盖：
- **三大特性**：封装、继承、多态（含代码示例）
- **核心语法**：类与对象、接口、异常处理、集合框架
- **项目报告模板**：功能说明、代码、输出效果、结果分析
- **评分要点**：功能(10%)、代码(40%)、效果(20%)、分析(20%)、总结(10%)

### [03-ENSP基础命令](03-ENSP基础命令.md)
华为ENSP网络模拟器常用配置命令速查，涵盖：
- **VLAN配置**：创建VLAN、Trunk/Access端口、VLANIF接口
- **STP配置**：根桥设置、优先级
- **路由协议**：静态路由、默认路由、浮动路由、RIP、OSPF
- **NAT配置**：ACL、地址池、outbound、server映射、防火墙NAT
- **WLAN配置**：VLAN划分、DHCP、SSID/安全/VAP模板、AP组
- **常用查看命令**：display vlan/ip routing-table/ospf peer等
