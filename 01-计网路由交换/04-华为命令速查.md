# 华为路由器/交换机常用命令速查

## 1. 用户视图（< > 提示符）

| 命令 | 说明 |
|------|------|
| `display version` | 查看设备版本信息 |
| `display current-configuration` | 查看当前运行配置 |
| `display saved-configuration` | 查看已保存的配置 |
| `save` | 保存当前配置到Flash |
| `reboot` | 重启设备 |
| `ping <IP>` | 测试连通性 |
| `tracert <IP>` | 追踪路由路径 |
| `display arp` | 查看ARP表 |
| `display mac-address` | 查看MAC地址表 |
| `terminal monitor` | 开启终端日志显示 |
| `system-view` | 进入系统视图 |

## 2. 系统视图（[ ] 提示符）

| 命令 | 说明 |
|------|------|
| `sysname <名称>` | 设置设备名称 |
| `header login information <文本>` | 设置登录提示信息 |
| `user-interface console 0` | 进入Console线路配置 |
| `user-interface vty 0 4` | 进入VTY远程线路配置 |
| `authentication-mode password` | 设置认证模式为密码 |
| `set authentication password cipher <密码>` | 设置加密密码 |
| `idle-timeout <分钟>` | 设置超时时间 |
| `undo` | 取消/删除某配置 |
| `quit` | 返回上一级视图 |
| `return` / `Ctrl+Z` | 直接返回用户视图 |

## 3. 接口配置

| 命令 | 说明 |
|------|------|
| `interface GigabitEthernet 0/0/1` | 进入GE接口 |
| `interface Ethernet 0/0/1` | 进入以太网接口 |
| `ip address <IP> <掩码>` | 配置接口IP地址 |
| `undo shutdown` | 启用接口 |
| `shutdown` | 关闭接口 |
| `description <描述>` | 设置接口描述 |
| `duplex full` | 设置全双工 |
| `speed 100` | 设置速率为100Mbps |
| `port link-type access` | 设置端口为Access模式 |
| `port link-type trunk` | 设置端口为Trunk模式 |
| `port link-type hybrid` | 设置端口为Hybrid模式 |
| `port default vlan <ID>` | 设置端口默认VLAN |
| `port trunk allow-pass vlan <ID/all>` | Trunk口允许通过的VLAN |

## 4. VLAN配置

| 命令 | 说明 |
|------|------|
| `vlan <ID>` | 创建VLAN并进入VLAN视图 |
| `vlan batch <ID1> to <ID2>` | 批量创建VLAN |
| `description <描述>` | 设置VLAN描述 |
| `port-group <组名>` | 创建端口组 |
| `group-member <接口范围>` | 将接口加入端口组 |
| `interface Vlanif <ID>` | 进入VLANIF接口（三层） |
| `ip address <IP> <掩码>` | 配置VLANIF接口IP（网关） |

## 5. 路由配置

### 5.1 静态路由

| 命令 | 说明 |
|------|------|
| `ip route-static <目的网络> <掩码> <下一跳>` | 配置静态路由 |
| `ip route-static 0.0.0.0 0.0.0.0 <下一跳>` | 配置默认路由 |
| `ip route-static <目的网络> <掩码> NULL0` | 配置黑洞路由 |

### 5.2 RIP协议

| 命令 | 说明 |
|------|------|
| `rip` | 启动RIP进程 |
| `version 2` | 设置RIP版本2 |
| `network <网络号>` | 宣告网络 |
| `undo summary` | 关闭自动汇总 |
| `rip metricin <值>` | 设置接口入方向度量值 |

### 5.3 OSPF协议

| 命令 | 说明 |
|------|------|
| `ospf 1` | 启动OSPF进程（进程号1） |
| `area <区域号>` | 进入OSPF区域 |
| `network <网络号> <反掩码>` | 宣告网络 |
| `ospf cost <值>` | 设置接口OSPF开销 |
| `ospf timer hello <秒>` | 设置Hello间隔 |
| `ospf timer dead <秒>` | 设置Dead间隔 |
| `display ospf peer` | 查看OSPF邻居 |
| `display ospf brief` | 查看OSPF摘要信息 |

## 6. 查看与诊断命令

| 命令 | 说明 |
|------|------|
| `display ip routing-table` | 查看路由表 |
| `display interface brief` | 查看所有接口摘要 |
| `display ip interface brief` | 查看接口IP配置摘要 |
| `display vlan` | 查看VLAN信息 |
| `display stp` | 查看生成树状态 |
| `display port vlan` | 查看端口VLAN信息 |
| `display this` | 查看当前视图下的配置 |
| `display logbuffer` | 查看日志缓冲区 |
| `display cpu-usage` | 查看CPU利用率 |
| `display memory-usage` | 查看内存利用率 |
| `debugging arp` | 开启ARP调试（慎用） |
| `terminal debugging` | 终端显示调试信息 |
| `reset arp` | 清除ARP表 |
| `reset counters interface` | 清除接口计数器 |
