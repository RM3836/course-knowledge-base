# 01 - 核心概念

## OSI 七层模型

| 层次 | 功能 | 数据单元 | 关键协议 |
|------|------|----------|----------|
| 物理层 | 比特流传输 | Bit | — |
| 数据链路层 | 物理寻址、流量控制、差错控制 | Frame | Ethernet, PPP |
| 网络层 | 路由选择、拥塞控制 | Packet | IP, OSPF, RIP |
| 传输层 | 端到端应答、分组排序、流量控制 | Segment | TCP, UDP |
| 会话层 | 建立/管理/终止会话 | — | — |
| 表示层 | 数据加密、压缩、格式转换 | — | — |
| 应用层 | 用户接口 | — | HTTP, DNS, FTP |

## TCP/IP 四层模型

```
应用层       ← HTTP, DNS, FTP, SMTP
传输层       ← TCP, UDP
网际层       ← IP, ICMP, ARP
网络接口层   ← Ethernet, Wi-Fi
```

## 关键协议速查

| 协议 | 功能 | 层次 | 记忆要点 |
|------|------|------|----------|
| `ARP` | IP → MAC 地址解析 | 网络层 | 地址解析协议 |
| `DNS` | 域名 → IP 解析 | 应用层 | 域名系统 |
| `DHCP` | 动态分配 IP/子网掩码/网关 | 应用层 | 自动配置 |
| `NAT` | 私有地址 ↔ 公有地址转换 | 网络层 | 节省公网IP |
| `OSPF` | 链路状态路由协议 | 网络层 | 开放最短路径优先 |
| `RIP` | 距离矢量路由协议 | 应用层 | 最大15跳 |
| `ICMP` | 网络控制消息 | 网络层 | ping/tracert |

## 私有地址范围（RFC 1918）

| 类别 | 范围 | 子网掩码 |
|------|------|----------|
| A 类 | `10.0.0.0 ~ 10.255.255.255` | `/8` |
| B 类 | `172.16.0.0 ~ 172.31.255.255` | `/12` |
| C 类 | `192.168.0.0 ~ 192.168.255.255` | `/16` |

## 传输方式

| 方式 | 说明 | 例子 |
|------|------|------|
| 串行传输 | 数据位按顺序逐位传输 | 串口通信 |
| 并行传输 | 多条信道同时传输 | 内部总线 |
| 单工 | 只能单向传输 | 广播电视 |
| 半双工 | 双向但交替进行 | 对讲机 |
| 全双工 | 可同时收发 | 电话 |

## 线缆标准

| 标准 | 线序 |
|------|------|
| T568B | 橙白、橙、绿白、蓝、蓝白、绿、棕白、棕 |
| T568A | 绿白、绿、橙白、蓝、蓝白、橙、棕白、棕 |

**线缆使用场景**：
- **直通线**：两端相同线序 → 不同设备（PC↔交换机、路由器↔交换机）
- **交叉线**：一端A一端B → 相同设备（PC↔PC、交换机↔交换机）

## DNS 域名解析过程

```
用户输入 www.baidu.com
  ↓
1. 检查本地缓存（浏览器→操作系统）
  ↓ 未命中
2. 查询本地 DNS 服务器
  ↓ 未命中
3. 查询根域名服务器 → 返回 .com 顶级域地址
  ↓
4. 查询 .com 顶级域 → 返回 baidu.com 权威域地址
  ↓
5. 查询权威域名服务器 → 返回 www.baidu.com 的 IP
  ↓
6. 缓存结果，返回给主机
```

## 网络性能指标

| 指标 | 定义 | 单位 |
|------|------|------|
| 带宽 | 信道最高数据率 | bit/s |
| 吞吐量 | 实际数据传输速率 | bit/s |
