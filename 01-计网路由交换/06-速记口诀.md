# 速记口诀

## 1. OSI七层模型口诀

**口诀：物数网传会表应**
（物理层、数据链路层、网络层、传输层、会话层、表示层、应用层）

**解释：** 自底向上七层结构。助记："巫术王传回北京"（物数网传会表应）

## 2. 路由优先级口诀（华为设备）

**口诀：直连0，OSPF是10，静态60，RIP是100**

| 路由类型 | 优先级（越小越优先） |
|----------|----------------------|
| 直连路由 | 0 |
| OSPF | 10 |
| 静态路由 | 60 |
| RIP | 100 |

**解释：** 记住"0-10-60-100"，优先级数值越小，路由越优先。

## 3. 线缆口诀

**口诀：交叉对同类，直连对异类**
（同类型设备用交叉线，不同类型设备用直通线）

**解释：**
- 直通线（Straight-through）：PC↔交换机、交换机↔路由器（异类设备）
- 交叉线（Crossover）：PC↔PC、交换机↔交换机、路由器↔路由器（同类设备）
- 现代设备大多支持Auto-MDI/MDIX，自动识别线序

**线序口诀：**
- T568B标准：白橙、橙、白绿、蓝、白蓝、绿、白棕、棕
- T568A：将1-3、2-6互换

## 4. 私有地址口诀

**口诀：A类一个10，B类一个172.16到31，C类一个192.168**

| 类别 | 私有地址范围 |
|------|--------------|
| A类 | 10.0.0.0 ~ 10.255.255.255 （1个A类网段） |
| B类 | 172.16.0.0 ~ 172.31.255.255 （16个B类网段） |
| C类 | 192.168.0.0 ~ 192.168.255.255 （256个C类网段） |

**解释：** "一十、十六、二百五十六"，记住每类私有地址的数量和起始地址。

## 5. DNS解析口诀

**口诀：先查本地，再查递归，根域先行，逐级权威**

**解析过程：**
1. 检查浏览器缓存 → 系统hosts文件 → 本地DNS缓存
2. 向本地DNS服务器发起递归查询
3. 本地DNS向根DNS服务器发起迭代查询
4. 根DNS返回顶级域（.com）服务器地址
5. 顶级域返回二级域（baidu.com）权威DNS地址
6. 权威DNS返回最终IP地址

## 6. RIP vs OSPF口诀

**口诀：RIP数跳数，OSPF看带宽；RIP慢收敛，OSPF快收敛**

| 特性 | RIP | OSPF |
|------|-----|------|
| 协议类型 | 距离矢量 | 链路状态 |
| 度量值 | 跳数（最大15） | 开销Cost（基于带宽） |
| 收敛速度 | 慢（30秒更新） | 快（触发更新） |
| 适用规模 | 小型网络 | 大中型网络 |
| 算法 | Bellman-Ford | Dijkstra（SPF） |
| 报文传输 | UDP 520端口 | IP协议号89 |
| 防环机制 | 水平分割、毒性逆转 | SPF算法天然无环 |

**解释：** RIP像数路标（跳数），OSPF像看路况（带宽），所以OSPF选路更优。

## 7. 其他实用口诀

### TCP三次握手口诀
**"发syn，回syn+ack，再ack"**
→ 请求→确认→确认的确认，建立连接

### 四次挥手口诀
**"发fin，回ack，再发fin，回ack"**
→ 各自关闭发送通道，四次完成断开

### 子网划分口诀
**"借一位翻一倍，减二可用"**
→ 借n位可划分2^n个子网，每个子网2^(32-n)-2个可用主机

### 传输层协议口诀
**"TCP可靠慢，UDP快但丢"**
→ TCP有连接可靠传输，UDP无连接尽最大努力交付
