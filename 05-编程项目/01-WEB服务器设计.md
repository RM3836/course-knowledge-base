# 01-WEB服务器设计

## 一、项目概述

基于C语言实现的HTTP Web服务器，支持GET和POST请求方法，采用守护进程模式运行，通过套接字进行网络通信。

### 系统特性
- 操作简单，易用
- 数据存储可靠，处理效率高
- 系统安全、稳定
- 功能完备、扩展性强

## 二、HTTP协议基础

### 请求报文结构
```
┌─────────────┐
│   请求行     │  方法 URL 协议版本
├─────────────┤
│  请求头部    │  Host, Content-Type等
├─────────────┤
│   空行       │
├─────────────┤
│  请求数据    │  POST时的请求体
└─────────────┘
```

### 响应报文结构
```
┌─────────────┐
│   状态行     │  协议版本 状态码 状态描述
├─────────────┤
│  消息报头    │  Server, Content-Type, Date等
├─────────────┤
│   空行       │
├─────────────┤
│  响应正文    │  HTML/文件内容
└─────────────┘
```

### 常用状态码
| 状态码 | 含义 | 说明 |
|--------|------|------|
| 200 | OK | 请求成功 |
| 404 | Not Found | 资源未找到 |
| 501 | Not Implemented | 请求方法未实现 |

## 三、GET与POST方法对比

| 对比项 | GET | POST |
|--------|-----|------|
| 回退行为 | 无害，不重新提交 | 会重新提交请求 |
| 收藏URL | 可以 | 不可以 |
| 浏览器缓存 | 自动缓存 | 不缓存（除非手动设置） |
| 编码方式 | 仅URL编码 | 支持多种编码 |
| 历史记录 | 参数保留在URL中 | 参数不保留 |
| 长度限制 | URL长度有限制 | 无限制 |
| 数据类型 | 仅ASCII字符 | 无限制 |
| 安全性 | 较低（参数暴露在URL） | 较高 |

## 四、套接字通信流程

### 服务器端
```
socket() → bind() → listen() → accept() → 处理请求 → 终止连接
  创建套接字   绑定端口   开始监听   接受连接    读写数据
```

### 客户端
```
socket() → connect() → 发送/接收数据 → 终止连接
  创建套接字   连接服务器    读写数据
```

## 五、系统架构

### 前端页面

| 页面 | 功能 |
|------|------|
| Index.html | 首页，显示主要功能 |
| Get.html | 显示GET方法提交的报文内容 |
| Post.html | 显示POST方法提交的报文内容 |
| Pho.html | 显示图片内容 |

### 后端函数（C语言）

| 函数 | 功能 |
|------|------|
| `int get_line(int sock, char *buf, int size)` | 从套接字读取一行请求 |
| `void response_200(int client, const char* path)` | 返回200 OK响应 |
| `void response_404(int client)` | 返回404 NOT FOUND |
| `void response_501(int client)` | 返回501 Method Not Implemented |
| `void response_file(int client, const char* path, int tag)` | 向客户端发送文件 |
| `void accept_request(int client)` | 处理客户端请求 |
| `void slove_get(int client, const char* path, const char* query)` | 处理GET请求 |
| `void slove_post(int client, const char* path, int cont_len)` | 处理POST请求 |
| `int start(int *port)` | 创建套接字并初始化 |
| `void init_daemon()` | 初始化为守护进程 |
